Configuration Guide
Parameter Files (.parm)

These files contain ArduPilot parameters that configure the behavior of SITL vehicles:

  • copter_demo.parm - Multi-rotor vehicle configuration
  • plane_demo.parm - Fixed-wing aircraft configuration
  • rover_demo.parm - Ground vehicle configuration
Key Parameters
Simulation
  • SIM_GPS_ENABLE - Enable GPS simulation
  • SIM_GPS_LAT/LON - Initial GPS position
  • SIM_SPEEDUP - Simulation speed multiplier
Vehicle
  • FRAME_CLASS - Vehicle frame type
  • FLTMODE1-6 - Flight mode assignments
  • FENCE_ENABLE - Enable geofencing
