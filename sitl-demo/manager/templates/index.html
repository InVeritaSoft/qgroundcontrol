Quick Start Guide
  1. Start the SITL services using the buttons above
  2. Open QGroundControl
  3. Go to Settings → Comm Links
  4. Add UDP connection: 127.0.0.1:14550
  5. Connect and start flying!
Ports: Copter: 14550, Plane: 14552, Rover: 14554
