# Load Per-Drone Missions

- From Area Planner
  - Configure area and multi-drone params
  - Use "Save Per-Drone Mission Files" to write WPL files

- Assign Vehicles
  - Map Drone i → Vehicle i in Area Planner mapping table

- Load Options
  - Option A: Use "Insert Drone # to Mission" to push into Plan view per vehicle
  - Option B: File → Open to load `.waypoints` per vehicle (verify target vehicle active)

- Verify
  - Mission items appear in Mission view per vehicle
  - Waypoint counts align with preview; altitudes include band offsets

- Notes
  - Ensure the correct vehicle is active before loading via menu
  - For batch operations, use mapping + "Upload All Mapped" in the next step
