# End-to-End SITL Test Checklist

- Setup
  - Follow `SITL-SETUP.md` and `SITL-CONNECT.md`

- Prepare Missions
  - Configure Area Planner; save per-drone WPLs
  - Load per vehicle or insert via Area Planner

- Upload
  - Use per-drone or mapped upload; observe progress/errors

- Validate
  - Altitude bands (`VALIDATE-ALTITUDE-BANDS.md`)
  - Time staggering (`VALIDATE-TIME-STAGGERING.md`)

- Evidence
  - Capture screenshots (`CAPTURE-SCREENSHOTS.md`)
  - Collect logs (`CAPTURE-LOGS.md`)

- Outcome
  - Summarize results, issues, and next actions
